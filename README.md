# DANZO FREE FIRE

Исходный код Telegram-бота DANZO FREE FIRE.

## Что уже есть

- Главное меню: каталог телефонов, настройки Free Fire, LITE, PRO, подписка и поддержка.
- Категории Samsung, iPhone, Redmi и POCO.
- Выбор модели телефона.
- SQLite для запоминания пользователей.
- Простая админ-панель по Telegram ID.
- Передача сообщений поддержки администраторам.

## Важно

Это первая рабочая версия каркаса, а не полностью готовый коммерческий бот.

- Каталог моделей пока стартовый, он не содержит все региональные варианты и все модели.
- Проверенные значения чувствительности LITE/PRO пока не добавлены. Бот прямо сообщает об этом и не выдумывает значения.
- Оплата и оформление подписки пока отключены.
- GitHub хранит исходный код, но сам по себе не запускает Telegram-бота.

## Запуск

Нужен Python 3.10 или новее и хостинг, который может запускать постоянный процесс.

Переменные окружения:
- `BOT_TOKEN` — токен от BotFather.
- `ADMIN_IDS` — Telegram ID администраторов через запятую, например `123456789,987654321`.
- `DB_PATH` — необязательный путь к SQLite-файлу (по умолчанию `danzo_free_fire.sqlite3`).

Запуск:

```bash
python bot.py
```

## Безопасность

Никогда не записывай токен в `bot.py`, README или публичный репозиторий. Добавляй его только в секреты/переменные окружения хостинга. Если токен публиковался в чате или репозитории, отзови его через BotFather и создай новый.
