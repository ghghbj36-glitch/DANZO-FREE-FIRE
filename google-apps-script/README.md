# Бесплатный запуск через Google Apps Script

Эта версия работает через Telegram webhook и не требует постоянно работающего Python-сервера.

## Важно сначала
Токен, который ранее был отправлен в чат, считай раскрытым. Отзови его в @BotFather командой /revoke и используй новый. Не присылай токен в чат и не добавляй его в GitHub.

## Настройка

1. Открой https://script.google.com/ и создай новый проект.
2. Открой файл Code.gs, удали примерный код и вставь содержимое файла Code.gs из этой папки репозитория.
3. В Apps Script открой Project Settings (значок шестерёнки) → Script properties → Add script property:
   - Property: BOT_TOKEN
   - Value: новый токен от BotFather
4. При необходимости добавь ADMIN_IDS со своим числовым Telegram ID. Пока можно пропустить.
5. Нажми Deploy → New deployment → тип Web app.
6. Execute as: Me. Who has access: Anyone. Нажми Deploy и подтверди разрешения Google.
7. После публикации выбери функцию installWebhook в списке функций редактора и нажми Run. Разреши доступ, если Google спросит.
8. Открой Telegram, найди @danzofreefirebot и отправь /start.

Если изменишь код после публикации, создай новую версию через Deploy → Manage deployments → Edit → New version → Deploy.

## Проверка
Открой URL веб-приложения, заканчивающийся на /exec. Должен появиться текст:
DANZO FREE FIRE webhook is online.

Если бот не отвечает, открой Apps Script → Executions и посмотри последнюю ошибку. Не публикуй токен или скриншоты, где он виден.

## Что пока не подключено
- Реальные проверенные чувствительности LITE/PRO.
- Оплата и автоматическое оформление подписки.
- Полный список всех моделей и вариантов телефонов.
- Расширенная админ-панель.
